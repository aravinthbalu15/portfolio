# **App Name**: Aravinth's Portfolio

## Core Features:

- Hero Section: Displays name, title, introduction, and call-to-action buttons (View Projects, Download Resume, Contact Me).
- About Section: Details Aravinth's background, specialization in MERN stack development, and internship experience.
- Skills Section: Lists programming languages, frontend and backend technologies, databases, and tools.
- Experience Section: Highlights professional experience, particularly the TCS iON Internship and contributions.
- Projects Section: Showcases personal projects with descriptions, tech stacks, live links, and GitHub repositories, styled as project cards.
- Education & Certifications: Presents educational background, achievements, and certifications to demonstrate expertise.
- Contact Information: Displays contact details including email, phone, LinkedIn, and GitHub profile, providing multiple contact options.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB). The sky blue represents a connection to digital space without being overly literal. It is also distinct from the typical blues found in similar portfolios.
- Background color: Dark navy (#1A232E), to convey depth and professionalism.
- Accent color: Electric blue (#7DF9FF), for highlights and interactive elements.
- Body text: 'Inter' sans-serif, providing a clean, modern aesthetic.
- Headline font: 'Space Grotesk' sans-serif for headings.
- Simple line icons for skills and technologies, consistent in style and color, chosen from the available font set.
- Card-based layout for projects to provide clear, organized information. 
- Subtle fade-in animations on scroll to create a smooth user experience.
